# Shopify Lookbook Feature

A native Shopify lookbook feature for a fashion store, built on the **Horizon**
theme. Lookbooks are modeled with **metaobjects**, rendered with **React +
TypeScript**, and product data is fetched at runtime through the **Storefront
API** — with no third-party apps.

## Highlights

- **Metaobject-driven** lookbooks (`title`, `description`, product **handles** only).
- **React** app bundled by Vite into a single theme asset and mounted into Liquid sections.
- **Storefront API** fetches product price / compare-at / image at runtime.
- **Market-aware pricing** for **AUD** and **JPY** via `@inContext(country:)`, including compare-at overrides.
- Two theme sections:
  - **Home page** — merchant chooses which lookbook to show.
  - **Product page** — no picker; auto-shows any lookbook the product is in (max 2).
- **CSS Modules** consuming Horizon design tokens so the lookbook inherits the theme's look.

## How it works

1. A merchant creates **Lookbook** metaobject entries in the admin, each holding
   a title, description, and a list of product **handles**.
2. Liquid reads the relevant lookbook(s) and embeds a small JSON payload
   (`{ lookbooks, settings, config }`) into a mount `<div>` — see
   [`snippets/lookbook-mount.liquid`](theme/snippets/lookbook-mount.liquid).
   - Home page: the single lookbook chosen in the theme editor.
   - Product page: every lookbook containing the current product, capped at 2.
3. The React app ([`src/main.tsx`](src/main.tsx)) hydrates each mount, then calls
   the Storefront API with `@inContext(country:)` to fetch live product data in
   the active market's currency, including compare-at overrides.

## Getting started

See [`docs/setup.md`](docs/setup.md) for the full walkthrough. Quick version:

```bash
npm install
npm run build        # -> theme/assets/lookbook.bundle.js + .css
npm run theme:dev    # push/preview theme with Shopify CLI
```

## Requirements coverage

| Requirement                                             | Where                                                             |
| ------------------------------------------------------- | ----------------------------------------------------------------- |
| Lookbooks render with React                             | `src/*`, mounted by `main.tsx`                                    |
| Product details via Storefront API                     | `src/api/storefront.ts`                                           |
| Correct currency per market (AUD/JPY) + compare-at      | `@inContext(country:)` + `Price.tsx`                              |
| Metaobject schema (title, description, products)        | `docs/metaobject-schema.md`                                       |
| Home page section, choose which lookbook                | `theme/sections/lookbook.liquid`                                  |
| Product page section, no picker, auto-detect            | `theme/sections/lookbook-product.liquid`                          |
| Max 2 lookbooks when product is in 3+                   | membership loop with `break` at 2                                 |
| Handles only; product data fetched at runtime           | metaobject stores handles; React fetches details                 |
| Native Shopify only (no third-party apps)               | metaobjects + Storefront API + theme sections                    |
