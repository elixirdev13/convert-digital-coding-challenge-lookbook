# Shopify Lookbook Feature

A native Shopify lookbook feature for a fashion store. Lookbooks are modeled with
**metaobjects**, rendered with **React + TypeScript**, and product data is fetched
at runtime through the **Storefront API** — with no third-party apps.

The feature is delivered as an overlay on a **Dawn-based** Online Store 2.0 theme
(the store's `test-data` theme). Because it relies only on standard OS 2.0 section
schema, metaobjects, and the Storefront API, the same sections work on any OS 2.0
theme (including Horizon).

## Highlights

- **Metaobject-driven** lookbooks (`title`, `description`, and a list of products).
- **React** app bundled by Vite into a single theme asset and mounted into Liquid sections.
- **Storefront API** fetches product price / compare-at / image at runtime.
- **Market-aware pricing** for **AUD** and **JPY** via `@inContext(country:)`, including compare-at overrides.
- Two theme sections:
  - **Home page** — merchant chooses which lookbook to show.
  - **Product page** — no picker; auto-shows any lookbook the product is in (max 2).
- **Configurable in the theme customizer:** columns, description toggle, and font
  sizes for heading, subheading, product title, and price.
- **Tailwind CSS**, scoped with an `lb-` prefix and Preflight disabled so it never
  restyles the host theme.

## How it works

1. A merchant creates **Lookbook** metaobject entries in the admin, each holding a
   title, description, and a list of products.
2. Liquid resolves each lookbook's product references down to **handles** and
   embeds a small JSON payload (`{ lookbooks, settings, config }`) into a mount
   `<div>` — see [`snippets/lookbook-mount.liquid`](theme/snippets/lookbook-mount.liquid).
   No product data (price/title/image) is stored in the metaobject.
   - Home page: the single lookbook chosen in the theme editor.
   - Product page: every lookbook containing the current product, capped at 2.
3. The React app ([`src/main.tsx`](src/main.tsx)) hydrates each mount, then calls
   the Storefront API with `@inContext(country:)` to fetch live product data in the
   active market's currency, including compare-at overrides.

## Getting started

See [`docs/setup.md`](docs/setup.md) for the full walkthrough. Quick version:

```bash
npm install
npm run build        # -> theme/assets/lookbook.bundle.js + .css (required before theme push)
npm run theme:dev    # push/preview theme with Shopify CLI
```

> The built bundle in `theme/assets/lookbook.bundle.*` is **gitignored**. Run
> `npm run build` after cloning (and before `shopify theme push`) so the theme has
> the compiled React app.

## Theme customizer settings

Display/styling is shared across the home-page and product-page lookbooks via
**Theme settings → Lookbook**, so configuring it once affects both. The only
per-section control is the lookbook **picker** on the home-page section.

Shared settings (Theme settings → Lookbook):

- **Columns** (2–4) — used for lookbooks with fewer than 4 products; lookbooks
  with 4+ products always render 4 per row
- **Show lookbook description** toggle
- **Image aspect ratio** (portrait / square / landscape)
- **Display products as a carousel** toggle — swipeable slider instead of a grid
- **Colors:** text color and full-width background color (blank = inherit)
- **Typography:** heading / subheading / product title / price font sizes (px)

Per-section:

- **Home page** — **Lookbook** picker (which lookbook to display)
- **Product page** — no picker; auto-detects lookbooks containing the product

### A note on the Storefront API token (for reviewers)

The token exposed on the storefront is a **public Storefront API access token**
(read-only, unauthenticated). It is *designed* to be sent to the browser — the
React app calls the Storefront API client-side at runtime, exactly like Shopify
Hydrogen and other headless storefronts. It is **not** an Admin API token and
cannot read orders or customer data.

To keep a non-technical merchant from accidentally clearing it (which would break
product fetching), the token is **not** surfaced as a theme setting. It is
hardcoded in [`theme/snippets/lookbook-mount.liquid`](theme/snippets/lookbook-mount.liquid)
and can be rotated in **Admin → Apps → (custom app) → API credentials** by
updating that value.

## Requirements coverage

| Requirement                                             | Where                                                             |
| ------------------------------------------------------- | ----------------------------------------------------------------- |
| Lookbooks render with React                             | `src/*`, mounted by `main.tsx`                                    |
| Product details via Storefront API                     | `src/api/storefront.ts`                                           |

| Home page section, choose which lookbook                | `theme/sections/lookbook.liquid`                                  |

| Handles only; product data fetched at runtime           | Liquid resolves references to handles; React fetches details      |
| Native Shopify only (no third-party apps)               | metaobjects + Storefront API + theme sections                    |
